# Bangla News 24

Bangla News 24 is a modern Bangla news portal built with Next.js and Tailwind CSS. The project is designed to provide a clean, fast, and responsive reading experience for local and national news, with room to grow into a full-content publishing platform.

## Overview

This project is currently in its initial setup phase and includes a Next.js application foundation for building a news website with sections such as:

- Breaking news
- National and international coverage
- Politics, business, sports, and entertainment
- Featured content and article cards
- Responsive mobile-first layout

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- ESLint
- pnpm
